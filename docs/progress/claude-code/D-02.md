# Handoff: D-02 OSM network calibration (lead, Tier 2)

Ports the #59 design rules to the OSM capital network (`osm_capital_v1.json`, `OsmCapitalProvider`). All values are ASSUMPTION (synthetic design, no ACUD data).

## Changes
- Demand: `occupancy_fraction` 0.12 (the placeholder demand, about 12 m3/s, was beyond any pipe size); `pattern_land_use` maps land uses without a demand pattern (`residential_low` -> `residential`). `assumptions/` untouched.
- Pipes: transmission 1.2 m, submain 0.4 m.
- Source: ground clearwell, head 5 m above the site.
- Pumps: 3 duty + 1 standby, design head 75 m, peak factor 1.2.
- Tanks: on the main (`tanks.site: "main"`, nearest-main fallback when a sector has no transmission junction), one common grade (bottom 30 m above the highest junction), transmission-tier connection, diameter 40 m.
- Level control: `tank_0` on below 2.5 m, off above 7.0 m, `keep_on` 1 (bounded; tested).

## Measured (SIMULATION, standard tier, 2 days, seeds 1-3)
Min pressure at peak 33.7 m, min any time 30.5 m, max velocity 2.23 m/s, tank pinned-full share 0.02. The max static pressure is about 70 m at the lowest junction (no PRV zoning on the OSM network yet).
