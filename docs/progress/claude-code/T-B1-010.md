# Handoff: T-B1-010, `ug fetch-geometry` and the coverage report

Author: Claude Code (lead). Reviewer: Codex (adversarial, two rounds at most; log `docs/reviews/T-B1-010.md`). Tier 2: the owner merges.

## What it does
`ug fetch-geometry --area capital [--refresh | --offline] [--cache DIR] [--report]` fetches the public street network of the study area from the Overpass API into a local, git-ignored cache and writes a coverage report.
- **Area file** (`platform/ug_core/src/ug_core/geometry/areas/capital_v1.json`, `ASSUMPTION`): an anchor point from Wikidata (Q19588497, P625, CC0), a search half-width, a 3 km margin, nine landmark names, `min_landmarks`. No OSM-derived geometry is committed (G2).
- **Fetch**: the landmarks are searched near the anchor; the study box is the bounding box of the ones found (per name the feature nearest the anchor) plus the margin, rounded outward; then roads and statistics are fetched in that box. A polite client: identifying User-Agent, spacing, exponential backoff on 429 and 5xx, no retry on a refused query; an answer with a `remark`, without a timestamp or element list, or failing its query's completeness checks is an error.
- **Cache** `<cache>/<area>/<OSM timestamp>/`: the answers byte for byte, the rendered queries, `provenance.json` (OpenStreetMap, ODbL-1.0, attribution, retrieval time, OSM timestamp, endpoint, the study box with how it was placed, per-query box, hashes). The cache must be git-ignored or outside any repository (checked before anything is written); writes are atomic; a corrupt or foreign extract of the same snapshot is replaced.
- **Verification** of a cached extract: the provenance against the current area file and templates, every hash, every answer's checks and timestamp, the boxes, the snapshot timestamp, the endpoint and the extract hash. A new extract passes the same checks before it is installed.
- **Report** (`report.json`, `report.md`, byte-identical across runs): street graph metrics for three road sets (length on the ways that touch the box and inside the box, junctions, dead ends, components, largest-component share), the share under construction, a 1 km grid, road length around each landmark, mapped features with a label per field (counts `OBSERVED`, Overpass kilometres `CALCULATED`), formulas.

## Live result (outside CI)
OSM timestamp 2026-10-26T12:39:20Z, all nine landmarks found: built drivable roads 2,736.1 km on the ways that touch the box, 2,373.8 km inside it; 11,727 junctions; 0.996 of the length in the largest component. The feasibility test gave 2,887.7 km, 12,451 and 0.977 in its own box; the part both boxes share holds 2,353.8 km in both extracts, so the difference is the box (`docs/audit/B1_GEOMETRY_FEASIBILITY.md` section 7).

## Tests
98 offline tests on a synthetic, hand-checkable grid (no OSM data): client, area file, study box, completeness, provenance verification (one test per check), same-snapshot repair, the cache boundary in temporary git repositories (tracked, ignored, ignored with a tracked file, symbolic link, git unable to answer, default from a subfolder), report numbers, labels, Markdown, CLI. Mutation runs: 13 in round 0, 38 after round 1 (37 caught; the survivor is equivalent, see the review log), plus the inside-box condition.
