## Decisions and review focus

1. `RunStore.new(manifest) -> RunDraft`; `write_truth(draft, series)` is privileged; `RunStore.write_table(draft, name, arrow_table)` adds consumer output; `RunStore.write(draft) -> run_id` publishes the complete set. Published runs are immutable. This makes all Parquet files and the manifest visible together through one `os.replace`, without a multi-file append transaction. Callers must assemble all tables before publication. A second complete draft for the same manifest must have exactly the same output set and hashes or it is refused.
2. The existing `Manifest.to_dict()` has no `run_id` field. No schema is changed: `manifest.json` is exactly canonical JSON of `manifest.with_output_hashes(...).to_dict()`. Verification recomputes `run_` plus the first 16 characters of `input_hash()` and compares it to the folder name. Unknown/missing/noncanonical manifest fields fail verification.
3. Keys are declared in `layout.py`: `(tick, element_id, quantity)` for the privileged bundle, `(tick, sensor_id)` for telemetry/expectation/quality, `(tick,)` for detector output. Detector suffixes use the existing identifier grammar. Duplicate or null keys are rejected instead of requiring an arbitrary tie-breaker.
4. Hash input is canonical JSON `{columns, key, label, rows}`. Columns carry name, Arrow type and nullability, in schema order; rows are arrays in that order, sorted by key. Float values, including nested values, use `round_for_hash`. Hashing feeds row JSON incrementally into SHA-256; file bytes and compression are excluded. Actual stored values retain their precision.
5. Evidence is Parquet schema metadata `label`: SIMULATION for the privileged bundle, MODEL for expectation; defaults SENSOR_SIM for telemetry, CALCULATED for quality and MODEL for detector output. Only valid evidence labels and no unrelated schema metadata are accepted. Consumer reads return raw row dictionaries; this persistence layer does not render a UI. Future displays must preserve the table's evidence label.
6. Only `truth_bundle.py` imports `ug_core.truth`. Other modules use schema/key descriptions and pass `truth_violations(..., any_truth_import=True)`. Consumer writes reject the honesty helper's stems and truth-only field names, including nested fields even if all their values are null. The privileged reader is not re-exported by the store package.
7. Active event kinds are sorted and joined with `+`; duplicate active kinds remain repeated. Matching uses exact element identity and an end-exclusive window; an unbounded event ends at the timebase end. Channel splitting uses the first colon only.
8. Every `RunReader.read_table` re-verifies the run, as well as `open()` verifying it. This catches damage after opening, at the cost of scanning all output tables for each read. Hashing/sorting and drafts are in memory: not a bounded-memory streaming implementation. Review this cost before using it for high-frequency replay; no replay latency claim is made.
9. An executed nested-list regression test initially failed: PyArrow's default Parquet writer changed a child name from `item` to `element`, changing the schema hash. A local probe verified `use_compliant_nested_type=False` preserves the name, and the writer now passes that option. The regression passes on the final code. No existing module was changed to resolve it.

No implementation blocker remains. Main review focus: the draft lifecycle/API, privileged boundary, hash encoding, atomic race handling, label inheritance by future displays, and the deliberate per-read verification cost.

Reproduction script:

```python
from datetime import UTC, datetime
from pathlib import Path
from tempfile import TemporaryDirectory
from time import perf_counter

import pyarrow as pa
from ug_core.manifest import Manifest
from ug_core.store import RunStore, StoreError
from ug_core.store.truth_bundle import write_truth
from ug_core.timebase import Timebase
from ug_core.truth import TruthEvent, TruthSeries


def recipe(config):
    return Manifest(config=config, seed=42, versions={'store':'1'}, libraries={'pyarrow':'26.0.0','duckdb':'1.5.6'})


with TemporaryDirectory(prefix='ug-store-demo-') as temporary:
    root = Path(temporary)
    store = RunStore(root)
    run = store.new(recipe({'fidelity':'F1','source':'SIMULATED','ticks':288}))
    axis = Timebase(datetime(2026,1,1,tzinfo=UTC),300,288)
    channels = {f'{quantity}:j{element}':[float(30 + element + tick % 7) for tick in axis.ticks()] for element in range(3) for quantity in ('pressure','demand')}
    write_truth(run, TruthSeries(axis,channels,(TruthEvent('leak','j1',100,120),)))
    store.write_table(run,'expectation',pa.table({'tick':[3,1,2,0,1,2],'sensor_id':['b','b','a','a','a','b'],'expected_value':[30.,31.,32.,33.,34.,35.],'sigma':[0.1]*6}))
    identifier = store.write(run)
    print('SIMULATION demo: 3 elements x 2 quantities x 288 ticks = 1728 rows; F1; SIMULATED')
    print('run_id:',identifier)
    print('output_hashes:',dict(store.verify(identifier).output_hashes))
    print('folder:', sorted(p.name for p in (root/identifier).iterdir()))
    reader = store.open(identifier)
    print('MODEL expectation window [1,3):',reader.read_table('expectation',ticks=(1,3)))
    try:
        reader.read_table('truth')
    except StoreError as exc:
        print('read_table(truth): StoreError:',exc)

with TemporaryDirectory(prefix='ug-store-week-') as temporary:
    store = RunStore(temporary)
    run = store.new(recipe({'fidelity':'F1','source':'SIMULATED','junctions':260,'quantities':4,'ticks':2016}))

    channels = {f'{quantity}:j{element:03}':[float(30 + element % 5 + tick % 7) for tick in axis.ticks()] for element in range(260) for quantity in ('pressure','demand','head','flow')}

    print('benchmark output_hashes:',dict(result.output_hashes))
```
