## Decisions and review focus

- `config` accepts a complete mapping (use `load_config()` and edit a copy). Structural count limits stay zero and solving stays mandatory; the numerical hydraulic thresholds are configurable. The loader validates the exact versioned keys, evidence label, unverified status, finite nonnegative thresholds and pinned-full share in (0, 1].
- Each `CheckResult.label` is CALCULATED. `threshold_label` is ASSUMPTION when a threshold exists; details explicitly identify network data or SIMULATION as the source. `passed=None` distinguishes skipped/informational checks. A tankless/pipe-less network passes those absent-element rules with value `None`; absent positive demand makes pressure/share N/A, never a fabricated zero.
- `horizon_days: float = 7.0` is added to both public functions for fast fixtures. Horizons must contain a positive whole number of five-minute intervals. Both endpoints are included: a seven-day run has 2,017 report ticks and 2,016 intervals, starting at the packaged `normal_week.start`. Tank occupancy and extrema include endpoints. Delivered/requested volume holds each sample over the following interval and excludes the final endpoint, matching solver energy integration.
- Demand comes from `DemandModel(load_assumptions("assumptions/demand_v1.yaml"))`, the caller's seed and an empty `DemandCalendar`. That assumptions path is relative to the caller's working directory; execution is intended from the repository root. No assumption fallback or implicit seed is introduced.
- Pressures exclude zero-base-demand junctions. Peak selects the first maximum of total **requested** demand. Velocity uses absolute magnitude. Tank starvation compares minimum clearance strictly above the margin; near-full occupancy includes levels at/above maximum minus margin (including WNTR overshoot) and fails at or above the configured share. Near-full ticks need not be consecutive.
- Ties select the earliest tick, then sorted element ID. Tank-pinned detail gives the first near-full tick for the tank with the largest occupancy share; tick zero is used if none are near full. Structural details name every violating element. Run-wide aggregates have no single worst element/tick and say so.
- Equal WNTR runs showed machine-precision drift (~4e-14 m/s) in a fixture velocity. Report values use the existing `ug_core.numeric.round_for_hash` six-decimal precision; pass/fail comparisons still use unrounded results. Review near-threshold numerical behavior: rounded display equality can coexist with a strict-margin failure. No solver code was changed.
- Procedural seven-day runs remain manual; the measured runs exceed the owner's 20-second CI inclusion limit. They assess synthetic F0 hydraulics, not any real network or field validation. The provider and its config are unchanged.
