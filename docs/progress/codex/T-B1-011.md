## Decisions and limits

- The owner prompt overrides the older task-card paths: configuration is packaged
  JSON loaded with `importlib.resources`, not a new file under `assumptions/`.
- Grid junction counts are allocated by district area using largest remainders.
  Each district starts with connected east-west streets and a north-south spine;
  additional adjacent grid streets meet the pipe target. The transmission ring
  and configured pumped radials are straight synthetic connector streets.
- Each random purpose uses exactly one of the six named `SeedStreams` generators.
  The constructor snapshots the complete config through canonical JSON; config
  provenance uses the existing core canonical JSON and SHA-256 implementation.
- Land-use demand is district hectares times the configured m3/s/ha rate, divided
  by independently seeded positive weights. Pump and valve auxiliary junctions
  have zero demand. All pipe diameters and roughness C values come from config.
- Tanks use the highest grid site within each configured group of zones, plus a
  configured practical offset and, for the elevated tank, a pedestal height. The
  reservoir is near the highest grid site with a configured head above terrain.
- Valves replace the downstream fraction of a street pipe in series, with a new
  zero-demand junction. They do not introduce a parallel pipe bypass. The pipe
  portion is exactly its Euclidean endpoint length; the valve occupies the
  remaining fraction of the original street segment. The model has no valve
  length, so reported total pipe length excludes those short valve spans.
- Sensor selection greedily maximizes diminishing-return coverage of graph-hop
  neighborhoods with seeded tie ordering. This is a structural coverage proxy,
  not hydraulic observability. One representative duty-pump discharge per station
  is mandatory in base/dense flow sets; the remainder are district radial inlets.
  Per-kind prefixes form strict sparse/base/dense subsets.
- Disconnected configurations raise `ValueError` listing unreachable junctions.
  No connectivity repair, automatic reseeding or hydraulic validation is done.
  Infeasible pipe targets and sensor counts fail explicitly.
- No model blocker encountered. Uncertainty: this F0 fixture has not been checked
  for hydraulic feasibility; pumps, PRVs, demands and storage require T-B1-014.
  NumPy stream reproducibility is conditional on the installed NumPy version,
  as documented by `SeedStreams`; the observed version here is 2.4.6.
